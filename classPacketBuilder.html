Detailed Description

Fluent Builder for Packet objects.

Usage: Packet p = PacketBuilder() .setType(PacketType::MESSAGE) .setFrom("alice").setTo("bob") .setBody(encryptedBody).setKey(wrappedKey) .build();

build() throws std::logic_error if setType() was not called.
