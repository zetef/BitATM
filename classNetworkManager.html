Detailed Description

Proxy to the BitATM WebSocket server with integrated E2EE and local history.

Handles connection lifecycle, packet serialization, RSA keypair management (QSettings-persisted), per-peer AES key wrapping, routing of inbound packets to typed signals, and write-through message persistence.

Threading: all methods run on the Qt main thread via the event loop. QWebSocket is async - no manual thread management needed.
