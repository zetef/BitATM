Detailed Description

template<typename T>
class BaseSqlRepository< T >

Abstract middle layer for PostgreSQL-backed repositories.

Owns the mapped table name and the shared Poco::Data plumbing, and implements remove() once - every mapped table has id SERIAL PRIMARY KEY. findById(), findAll() and save() stay pure from IRepository, so the class is abstract.
